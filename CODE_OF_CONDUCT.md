# Code of conduct

## The short version

Be decent to each other. Assume good faith. Critique code, not people.

## What that means in practice

- Welcome questions, including basic ones. Everyone was new once, and "obvious"
  is a property of experience rather than of intelligence.
- Give feedback on the work, not the person. "This loop runs once per row and
  could be vectorised" is useful; "this is sloppy" is not.
- Accept feedback the same way. A review comment is about the code.
- Assume the other person had a reason. Ask what it was before concluding they
  were careless.
- Disagreement is fine and often productive. Contempt is not.

## Not acceptable

Harassment, personal attacks, discriminatory language, or publishing other
people's private information.

## Reporting

If someone's behaviour is a problem, raise it with the repository owner. Reports
are taken seriously and kept confidential.

## Scope

This applies in issues, pull requests, commit messages, code comments, and
anywhere else this project is discussed.
